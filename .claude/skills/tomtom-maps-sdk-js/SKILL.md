## Global conventions

- **Coordinates**: `[longitude, latitude]` — longitude first (GeoJSON order)
- **Place, route, range, geometry and traffic services return GeoJSON**: `Place = Feature<Point>`, `Places = FeatureCollection<Point>`; `reverseGeocode` and `getPlaceDetails` return one `Place`, `geometryData` polygons. **Not GeoJSON**: `getPOICategories`, `getPOICategoryCodes`, `evChargingStationsAvailability` and `getSearchSuggestions` — show `getPlacesWithEVAvailability`'s places, not the availability records
- **Map modules are async**: `await Module.create(map)` for data-owned modules (Places, Routing, Geometries, CustomGeoJSON, TrafficIncidentDetails, TrafficAreaAnalytics — a new independent instance per call), `await Module.get(map)` for style-owned ones (BaseMap, POIs, TrafficFlow, TrafficIncidents, Terrain — a shared controller)
- **`geocodeOne()` throws** if no result — use `geocode()` when uncertain
- **`discoverOnePlace()` throws** if no result — use `discoverPlaces()` when uncertain
- **Services work in Node.js** — no browser or map required
- **Map container CSS**: The map div AND `html, body` all need explicit height (`height: 100%` or `100vh`) and `margin: 0` — without this the map renders with zero height. Always include a complete HTML + CSS boilerplate in your answer, not just the TypeScript.
- **SDK first, MapLibre beneath**: `map.mapLibreMap` is the real MapLibre `Map`, so any MapLibre API, control or plugin works — but use the SDK feature wherever one exists: it survives `setStyle` and style upgrades, coordinates events, and follows the map's theme. Your own GeoJSON goes through `CustomGeoJSONModule` (`custom.md`), even for one layer; raw `addSource`/`addLayer` is for tile overlays. Which SDK feature replaces which raw call: `maplibre.md` § SDK first.
- **Layer placement**: `beforeId`/`beforeID` inserts a custom layer **below** any style layer, but use the `mapStyleLayerIDs` anchors from `@tomtom-org/maps-sdk/map` — they are stable across styles. Default **lines and polygons to `mapStyleLayerIDs.lowestLabel`** so all labels stay above them (the SDK's own default); points and markers go on top, with no anchor. Anchor table in `maplibre.md` (raw `addLayer`) and `custom.md` (`CustomGeoJSONModule` specs).
- **Provide visible UI feedback** for event handlers (toasts, panels, info bars) — not just `console.log`. Build real, functional UI that the user can see and interact with.
