The map above is the [default map example](../examples/default-map), and this is its code:

```javascript
import { TomTomConfig } from '@tomtom-org/maps-sdk/core';
import { TomTomMap } from '@tomtom-org/maps-sdk/map';

TomTomConfig.instance.put({ apiKey: 'YOUR_API_KEY', language: 'en-GB' });

new TomTomMap({
    mapLibre: {
        container: 'map',
        center: [4.8156, 52.4414],
        zoom: 8,
    },
});
```

`container` is the id of the page element the map fills, so give that element a height.

## Quickstart

1. **Get your TomTom API key:**

- Sign up or log in at [my.tomtom.com](https://my.tomtom.com/).

- Create an API key following these [instructions](https://docs.tomtom.com/platform/documentation/dashboard/api-key-management).

<Blockquote>
    **Before you ship, decide where this key will live.** A key used from the browser can be read by anyone who opens the page; a key used from Node.js cannot. [Where your API key runs](../guides/security/where-your-api-key-runs.mdx) covers both cases.
</Blockquote>

2. **Install the SDK:**
```sh
# npm and Yarn install the peer dependencies for you
npm install @tomtom-org/maps-sdk

# pnpm does not, unless you ask it to
echo "auto-install-peers=true" >> .npmrc && pnpm add @tomtom-org/maps-sdk
```

3. **Start building:**
- Follow the [Map quickstart](../guides/map/quickstart.mdx) to display your first map.
- Or the [Services quickstart](../guides/services/quickstart.mdx) to call search, geocoding or routing.
- Or start from a runnable app in the [examples gallery](../examples).
- Using an AI coding agent? Install the [`tomtom-maps-sdk-js` skill](../guides/ai-coding.mdx) first.

[Project setup](./project-setup.mdx) has the requirements, peer dependencies and framework setups.

For AI agents, project setup and the quickstarts are also published as Markdown: [project setup](https://docs.tomtom.com/maps-sdk-js/introduction/project-setup.md), and the [map](https://docs.tomtom.com/maps-sdk-js/guides/map/quickstart.md), [services](https://docs.tomtom.com/maps-sdk-js/guides/services/quickstart.md) and [core](https://docs.tomtom.com/maps-sdk-js/guides/core/quickstart.md) quickstarts.

## Overview

**Maps SDK for JavaScript** is a **JavaScript/TypeScript** library for building applications with **TomTom** maps and location APIs.

It is built on [MapLibre GL JS](../guides/map/about-maplibre.mdx) and [GeoJSON](https://geojson.org/): TomTom maps and services work together out of the box, and the MapLibre map stays fully exposed, so its API and plugin ecosystem work alongside the SDK.

## Key features

- **Interactive maps**: TomTom styles on MapLibre, with modules for places, routes, traffic and your own data
- **Location services**: search, geocoding, routing, reachable ranges, EV charging availability and traffic
- **GeoJSON throughout**: a service result goes straight into a map module
- **TypeScript**: complete type definitions ship with the package
- **Tree-shakable**: your bundle carries only what you import

## Bundles

| Bundle | Runs in | Holds |
| --- | --- | --- |
| [**Map**](../guides/map/quickstart.mdx) | Browser | `TomTomMap` and its modules for places, routes, traffic and more |
| [**Services**](../guides/services/quickstart.mdx) | Browser, Node.js, React Native | One function per TomTom API, most returning GeoJSON |
| [**Core**](../guides/core/quickstart.mdx) | Anywhere | The shared configuration, types and utilities |

[How the SDK works](../guides/how-the-sdk-works.mdx) shows how the three fit together.
