    Class RouteDragging

    Edits a route by dragging on a RoutingModule: a waypoint's pin moves its stop, and a route line pulls a new stop off it. The routes re-plan as you drag.

    Remarks

    Public Preview until the plugin's 1.0.0 release.

    • It edits the waypoints the routing module last showed, so its indexes are the pins' own.
    • While a drag lasts, the routes re-plan every RouteDraggingOptions.planIntervalMS, and once more on the drop.
    • The requests overlap rather than cancel each other, so a route slower than the interval still shows during the drag. An answer older than one already shown is dropped, through createLatestRequest({ supersede: 'on-answer' }).
    • With showOnMap: false, it shows nothing itself, and your app shows what it reports.

    Example

    const routing = await RoutingModule.create(map);
    const dragging = new RouteDragging(routing);
    await dragging.setWaypoints([[4.9041, 52.3676], [5.1214, 52.0907]]);
