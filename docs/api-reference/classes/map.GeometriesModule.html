    Class GeometriesModule

    The module that displays polygon areas with custom styling on the map.

    It visualizes geographic areas (polygons) with customizable colours, borders, and labels. Use it to display search results, administrative boundaries, service areas, or any polygon-based geographic data.

    Remarks

    Features:

    • Display single or multiple polygon geometries
    • Customizable fill colors and opacity
    • Configurable borders (color, width, opacity)
    • Optional text labels for geometries
    • Support for data-driven styling via MapLibre expressions
    • Layer ordering control
    • Event handling for user interactions

    Data format:

    • Accepts GeoJSON Polygon and MultiPolygon features
    • Supports FeatureCollection for multiple geometries
    • Compatible with TomTom Search API geometry results
    • Reachable ranges have a module of their own, ReachableRangesModule

    Styling:

    • One colour, a palette of your own, or the map's accent by default
    • Apply MapLibre expressions for dynamic styling
    • Per-feature styling via feature properties

    Example

    Basic usage:

    import { GeometriesModule } from '@tomtom-org/maps-sdk/map';

    // Initialize module
    const geometriesModule = await GeometriesModule.create(map);

    // Display a polygon
    await geometriesModule.show({
      type: 'Feature',
      geometry: {
        type: 'Polygon',
        coordinates: [[[4.88, 52.37], [4.89, 52.37], [4.89, 52.38], [4.88, 52.38], [4.88, 52.37]]]
      },
      properties: {
        title: 'Area of Interest'
      }
    });

    Example

    Custom styling:

    const geometriesModule = await GeometriesModule.create(map, {
      fill: { color: '#FF5733', opacity: 0.3 },
      line: { color: '#C70039', width: 3 },
      label: {
        title: ['get', 'name']
      }
    });

    await geometriesModule.show(polygonFeatures);

    Example

    Multiple geometries with different colors:

    await geometriesModule.show({
      type: 'FeatureCollection',
      features: [
        {
          type: 'Feature',
          geometry: { type: 'Polygon', coordinates: [...] },
          properties: { color: '#FF0000', title: 'Red Zone' }
        },
        {
          type: 'Feature',
          geometry: { type: 'Polygon', coordinates: [...] },
          properties: { color: '#00FF00', title: 'Green Zone' }
        }
      ]
    });

    Example

    Event handling:

    geometriesModule.events.on('click', (feature, lngLat) => {
      console.log('Clicked geometry:', feature.properties.title);
      console.log('At coordinates:', lngLat);
    });

    geometriesModule.events.on('hover', (feature) => {
      showTooltip(feature.properties.title);
    });

    • applyConfig(config: GeometriesModuleConfig | undefined): void

      Applies a configuration to this module.

      The module updates its behaviour and appearance to match. It stores the configuration and reapplies it automatically when the map style changes.

      Parameters

    getConfig

    • getConfig(): NonNullable<GeometriesModuleConfig> | undefined

      Returns a shallow copy of the current module configuration, or undefined if none is applied.

      Returns NonNullable<GeometriesModuleConfig> | undefined

      A shallow copy of the current configuration, or undefined. It is a copy so that you can't modify the internal state by accident.

      Remarks

      Only the top-level properties are copied. Nested objects and arrays still reference the original configuration. This is enough for most use cases, but keep it in mind with complex configurations.

      Example

      // Apply a configuration
      myModule.applyConfig({ visible: true, color: '#E63312' });

      // Later, retrieve the current configuration
      const currentConfig = myModule.getConfig();
      console.log(currentConfig); // { visible: true, color: '#E63312' }

      // When no config is applied
      myModule.resetConfig();
      console.log(myModule.getConfig()); // undefined

      See

      • applyConfig to modify the configuration
      • resetConfig to clear the configuration

    setEventState

    • setEventState(options: SetEventStateOptions): void

      Puts an event state on one of the shown features, as a user interaction would.

      Parameters

      • options: SetEventStateOptions

      Returns void

      Remarks

      The state is what the module's own layers draw (place pins and entry points, route outlines, geometries, details-module incidents, area-analytics cells), what layers of yours read with ['get', 'eventState'], and what getEventStates returns. It lasts as long as the shown feature does, through setVisible, style and configuration changes, but not a new show, a clear or a setStyle with resetState.

      Example

      // Select a feature from a list, as a click would
      module.setEventState({ id: feature.properties.id, state: 'click' });

      // Hover a second one without taking the hover off the first
      module.setEventState({ index: 2, state: 'hover', mode: 'add' });

    show

    • show(geometries: PolygonFeatures): Promise<void>

      Displays the given polygon geometries on the map.

      Parameters

      • geometries: PolygonFeatures

        The polygon features to display, as a single Feature, an array of Features, or a FeatureCollection.

      Returns Promise<void>

      Remarks

      • Replaces any previously shown geometries
      • Applies current module styling configuration
      • Waits for module to be ready before displaying
      • Automatically handles both Polygon and MultiPolygon types

      Feature properties:

      • title: Used for labels if label is not set
      • color: Override fill colour per feature
      • fillStyle: Override the module's fill.style per feature
      • id: The id that event states and event handlers use, generated when missing. A feature's top-level id isn't read, so the top-level id of a geometry data result matches nothing
      • Custom properties accessible in styling expressions

      Example

      Single polygon:

      await geometries.show({
        type: 'Feature',
        geometry: {
          type: 'Polygon',
          coordinates: [[[4.88, 52.37], [4.89, 52.37], [4.89, 52.38], [4.88, 52.37]]]
        },
        properties: {
          title: 'Amsterdam Center',
          color: '#FF5733'
        }
      });

      Example

      Multiple polygons:

      await geometries.show({
        type: 'FeatureCollection',
        features: [
          { type: 'Feature', geometry: {...}, properties: {...} },
          { type: 'Feature', geometry: {...}, properties: {...} }
        ]
      });

      Example

      From a place's geometry:

      import { geocodeOne, geometryData } from '@tomtom-org/maps-sdk/services';

      const amsterdam = await geocodeOne('Amsterdam');
      await geometries.show(await geometryData({ geometries: [amsterdam] }));

    Staticcreate

    • create(
          tomtomMap: TomTomMap,
          config?: GeometriesModuleConfig,
      ): Promise<GeometriesModule>

      Waits until the map is ready for any interaction, then creates an instance of the module.

      Parameters

      • tomtomMap: TomTomMap
      • Optionalconfig: GeometriesModuleConfig

        The optional module configuration.

      Returns Promise<GeometriesModule>

      A promise with a new instance of this module.

      Remarks

      Configuration options:

      • color: Base colour for fill and border
      • fill: Fill colour and opacity
      • line: Border/outline styling
      • label: Center label text and styling
      • beforeLayerConfig: Layer ordering, as a single target or { all, fill, line } to split them

      GeometriesModule owns the sources, layers and images it adds, all suffixed per instance. Every call therefore returns a new, independent instance, so you can put several on the same map, each managing a different set of geometries with different styles.

      Example

      Default initialization:

      const geometriesModule = await GeometriesModule.create(map);

      Example

      With custom styling:

      const geometriesModule = await GeometriesModule.create(map, {
        fill: { color: 'blue', opacity: 0.25 },
        line: { color: 'darkblue', width: 2, opacity: 0.8 },
        label: {
          title: ['get', 'title']
        },
        beforeLayerConfig: 'top'
      });

      Example

      Data-driven styling:

      const geometriesModule = await GeometriesModule.create(map, {
        fill: {
          // Color based on feature properties
          color: [
            'match',
            ['get', 'type'],
            'residential', '#FFEB3B',
            'commercial', '#2196F3',
            'industrial', '#9E9E9E',
            '#E0E0E0' // default
          ],
          opacity: 0.4
        }
      });
