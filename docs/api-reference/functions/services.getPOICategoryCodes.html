      Wraps getPOICategories to return a flat array of POICategory codes.

      The returned codes serve two purposes:

      • Pass to discoverPlaces({ filters: { poiCategories } }) to filter search results by category.
      • Pass as POIsModule filters.categories to filter the map's built-in POI icons. Generic parent codes (e.g. 'RESTAURANT') work there, but overly specific child codes (e.g. 'ITALIAN_RESTAURANT') don't, so use a parent or a POICategoryGroup instead.
