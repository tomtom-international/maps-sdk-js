      Returns a GeometriesModuleConfig for reachable ranges.

      Builds on themedGeometryConfig and overrides transformFeaturesForDisplay so the raw output of calculateReachableRanges can be passed directly to GeometriesModule.show — labels are derived from each feature's budget property.

      Parameters

      • palette:
            | "warm"
            | "browns"
            | "cold"
            | "fadedBlues"
            | "blues"
            | "greens"
            | "fadedGreenToBlue"
            | "blueToRed"
            | "greenToYellow"
            | "pastel"
            | "retro"
            | "contrastRetro"
            | "fadedRainbow"
            | "pastelRainbow" = 'fadedRainbow'

        Color palette. Defaults to 'fadedRainbow'.

      • Optionaltheme: GeometryTheme

        Visual theme. Defaults to 'filled'.

      • OptionalbeforeLayerConfig: GeometryBeforeLayerConfig

        Layer positioning. Defaults to 'lowestLabel'.

      • Optionallabel: ReachableRangeLabelFn

        Custom label generator; when omitted, labels are derived from budget property.

      Returns GeometriesModuleConfig

      Example

      const module = await GeometriesModule.create(map, reachableRangeGeometryConfig());
      const result = await calculateReachableRanges([...]);
      module.show(result); // labels and theme applied automatically
