    Type Alias AreaAnalyticsBeforeLayerConfig

    AreaAnalyticsBeforeLayerConfig: PartsBeforeLayerConfig<AreaAnalyticsDisplayMode>

    Where the area analytics layers sit in the map's layer stack.

    Remarks

    A single BeforeLayerConfig positions every display mode's layer. The record form positions them independently, keyed by AreaAnalyticsDisplayMode, with all covering any it doesn't name. A mode neither names keeps its default, 'lowestLabel' for heatmap, hexgrid-2d and square-2d, and 'lowestPlaceLabel' for hexgrid-3d and square-3d. The region boundary always sits below the map's labels.

    Example

    // Every mode on top of the map
    const config: TrafficAreaAnalyticsModuleConfig = { beforeLayerConfig: 'top' };

    // Flat modes below labels, extrusions below place labels
    const config: TrafficAreaAnalyticsModuleConfig = {
      beforeLayerConfig: { all: 'lowestLabel', 'hexgrid-3d': 'lowestPlaceLabel', 'square-3d': 'lowestPlaceLabel' },
    };
