    Optionalplan

    plan?: RouteDraggingPlanner | false

    Plans the routes for the waypoints, null placeholders left out.

    Pass your own to plan with your route options, or false to plan nothing and only get the waypoint changes.

    Default Value

    calculateRoute({ locations, signal })

    OptionalplanIntervalMS

    planIntervalMS?: number

    How often the routes re-plan while a drag lasts, in milliseconds. The drop always plans once more.

    Default Value

    500

    OptionalshowOnMap

    showOnMap?: boolean

    Whether the plugin shows the dragged waypoints and the planned routes on the routing module.

    Set it to false when your app shows them itself: apply each change onWaypointsChange reports and show the routes onRoutes receives.

    Default Value

    true
