    Type Alias TrafficAreaAnalyticsLayersConfig

    MapLibre overrides for the layers TrafficAreaAnalyticsModule draws, for what its configuration doesn't cover. Each display mode draws its own layers. heatmap draws the heatmap, hexgrid-2d the hexagon fill and outline, hexgrid-3d the hexagon extrusion and its highlight, and the same for the square grid. The region boundary is drawn in every mode.

    Remarks

    Each entry is a partial layer spec merged onto the module's own. Top-level fields replace, layout and paint merge per property, and what you set here takes precedence over the module's own settings, the active metric's colours and heights included. A cell layer's filter applies together with the active metric's filters. beforeLayerConfig decides where the layers sit, so a beforeID here is ignored.

    Example

    layers: {
        hexgridFill: { paint: { 'fill-opacity': 0.85 } },
        hexgridExtrusion: { paint: { 'fill-extrusion-vertical-gradient': false } },
        regionLine: { paint: { 'line-dasharray': [2, 2] } },
    }
    type TrafficAreaAnalyticsLayersConfig = {
        heatmap?: Partial<ToBeAddedLayerSpecTemplate<HeatmapLayerSpecification>>;
        hexgridExtrusion?: Partial<
            ToBeAddedLayerSpecTemplate<FillExtrusionLayerSpecification>,
        >;
        hexgridExtrusionHighlight?: Partial<
            ToBeAddedLayerSpecTemplate<FillExtrusionLayerSpecification>,
        >;
        hexgridFill?: Partial<ToBeAddedLayerSpecTemplate<FillLayerSpecification>>;
        hexgridOutline?: Partial<
            ToBeAddedLayerSpecTemplate<LineLayerSpecification>,
        >;
        regionFill?: Partial<ToBeAddedLayerSpecTemplate<FillLayerSpecification>>;
        regionLine?: Partial<ToBeAddedLayerSpecTemplate<LineLayerSpecification>>;
        squareExtrusion?: Partial<
            ToBeAddedLayerSpecTemplate<FillExtrusionLayerSpecification>,
        >;
        squareExtrusionHighlight?: Partial<
            ToBeAddedLayerSpecTemplate<FillExtrusionLayerSpecification>,
        >;
        squareFill?: Partial<ToBeAddedLayerSpecTemplate<FillLayerSpecification>>;
        squareOutline?: Partial<ToBeAddedLayerSpecTemplate<LineLayerSpecification>>;
    }
