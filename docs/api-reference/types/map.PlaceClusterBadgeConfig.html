    Type Alias PlaceClusterBadgeConfig

    Appearance of the cluster count badge under the pin-clustered marker type.

    Remarks

    Each field applies to single-category and mixed-category clusters alike. The matching PlaceLayersConfig entry (clusterBadge, clusterCount, clusterMixedBadge, clusterMixedCount) overrides it for the paint and layout properties it names.

    type PlaceClusterBadgeConfig = {
        color?: DataDrivenPropertyValueSpecification<string>;
        label?: Pick<LabelConfig, "color" | "size">;
        offset?: [number, number];
        outlineColor?: DataDrivenPropertyValueSpecification<string>;
        outlineWidth?: DataDrivenPropertyValueSpecification<number>;
        radius?: { mixed?: number; single?: number };
    }

    Properties

    Optionalcolor

    color?: DataDrivenPropertyValueSpecification<string>

    Badge fill color.

    Default

    '#000000'

    Optionallabel

    label?: Pick<LabelConfig, "color" | "size">

    The count inside the badge.

    Remarks

    color defaults to '#FFFFFF' and size to 12 pixels.

    Optionaloffset

    offset?: [number, number]

    Offset of the single-category badge from the cluster icon, in viewport pixels.

    Remarks

    Applied to the badge circle and the count text together so they can't drift apart. Mixed-category clusters are always centred and ignore this.

    Default

    [12, -14]

    OptionaloutlineColor

    outlineColor?: DataDrivenPropertyValueSpecification<string>

    Badge outline color.

    Default

    '#FFFFFF'

    OptionaloutlineWidth

    outlineWidth?: DataDrivenPropertyValueSpecification<number>

    Badge outline width in pixels.

    Default

    1.5

    Optionalradius

    radius?: { mixed?: number; single?: number }

    Badge radius in pixels, per cluster kind.

    Remarks

    single is the small badge in the corner of a single-category cluster's icon. mixed is the centred badge that replaces the icon entirely for mixed-category clusters, so it defaults larger.

    Default

    { single: 11, mixed: 15 }
