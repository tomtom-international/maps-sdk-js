    Type Alias CountryCrossingConfig

    Appearance of the border crossings along a route.

    Remarks

    A crossing is the seam between two consecutive country sections, so it is a point rather than a stretch. It takes knobs of its own instead of a place in the section catalogue. Each is a label naming both countries by their ISO 3166-1 alpha-2 codes in the direction of travel, such as 'ES → FR', in a bubble standing above the route as the route summaries do.

    The bubble takes the selected route summary's default colours unless color or label.color says otherwise, so it follows the map's theme and colour knobs without being reconfigured. A summaryBubbles colour of yours does not reach it.

    A crossing gives way to the waypoint pins, the summaries and any symbol drawn above it: where one covers it, it hides.

    Example

    // `country` is among the default section types.
    const routes = await calculateRoute({ locations });
    await routing.showRoutes(routes);

    color?: string

    The bubble colour behind the label.

    Default Value

    the selected route summary's colour, SummaryBubblesConfig.color's default: the map's labelHalo lightened when a theme or the colors.labelHalo knob sets it, else white on a light style and dark grey on a dark one.

    Optionallabel

    label?: CountryCrossingLabelConfig

    The label naming the countries.

    OptionalminZoom

    minZoom?: number

    The lowest zoom a crossing is drawn at.

    Default Value

    4, low enough for a continental route to show its borders while framed whole.

    Optionalvisible

    visible?: boolean

    Whether the crossings are drawn.

    Default Value

    true
