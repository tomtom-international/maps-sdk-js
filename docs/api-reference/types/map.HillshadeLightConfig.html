    Type Alias HillshadeLightConfig

    The light the TerrainModule hillshade shades the relief with.

    type HillshadeLightConfig = {
        alignment?: HillshadeLightAlignment;
        altitude?: number;
        direction?: number;
    }
    Index

    Properties

    alignment? altitude? direction?

    Properties

    Optionalalignment

    alignment?: HillshadeLightAlignment

    What direction is measured from: the top of the screen, so the light turns with the camera, or north, so it stays on the same slopes as the map rotates.

    Default

    The style's own, viewport.

    Optionalaltitude

    altitude?: number

    Height of the light above the horizon, in degrees: 0 at sunset, 90 at noon. A low light casts longer shadows. Used by the basic, combined and multidirectional methods.

    Default

    The style's own, 45.

    Optionaldirection

    direction?: number

    Direction the light comes from, in degrees clockwise from the top of the screen, or from north with alignment: 'map' (335 is the cartographic default). With the multidirectional method, the centre of its four lights.
