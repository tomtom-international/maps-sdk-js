    The 3D surface of the TerrainModule, raised to the elevation data. Shows best with a pitched camera.

    Properties

    Optionalexaggeration

    exaggeration?: number

    Vertical scaling of the surface: 1 is true elevation, higher values emphasise the relief. Kept while visible is off, so turning it back on restores it.

    hillshade.exaggeration is a different thing: how strongly the slopes are shaded, raising nothing.

    Default

    1

    Optionalvisible

    visible?: boolean

    Raises the map surface in 3D, or flattens it.

    Default

    The map's own terrain, if its style or MapLibre code raised one; none on TomTom styles.
