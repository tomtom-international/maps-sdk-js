    Type Alias StyleChangeHandler

    Callbacks that respond to map style changes.

    Remarks

    The SDK calls them when the map style changes through TomTomMap.setStyle. Use them to clean up or reinitialize custom map features when the style switches. For example, save and restore custom layers or sources, reinitialize map modules, update UI components for the new style, or clean up resources tied to the previous style.

    The lifecycle is:

    1. onStyleAboutToChange runs before the new style is applied.
    2. The style changes.
    3. onStyleChanged runs after the new style has fully loaded.

    Example

    const styleHandler: StyleChangeHandler = {
      onStyleAboutToChange: () => {
        console.log('Style changing - saving state...');
        // Save custom layer data
      },
      onStyleChanged: () => {
        console.log('Style changed - restoring state...');
        // Restore custom layers
      }
    };

    const unsubscribe = map.addStyleChangeHandler(styleHandler);
    // Call unsubscribe() when the handler's owner is torn down.

    Remarks

    Use it to clean up or save state before the current style is removed. It can be synchronous or asynchronous. The SDK awaits it before handing the new style to MapLibre, so nothing of the old style is torn down while it runs.

    Remarks

    Use it to restore state, reinitialize layers or do other setup that depends on the new style being ready. It can be synchronous or asynchronous. Handlers run one after the other, in registration order, and the promise TomTomMap.setStyle returns resolves only once the last one has finished.

    Optionalpriority

    priority?: number

    Where this handler runs relative to the others. Lower values run first, and equal values run in registration order. The default 0 is also what the SDK's data and visibility modules use. The SDK's style knobs land at 90 and the StylingFoundationsModule's raw layer edits at 100, so semantic styling always lands on top of whatever the modules restored.

    Default

    0
