    Type Alias SectionIconConfig

    The icon drawn on a route section.

    Remarks

    Backed by a symbol layer over the section's own source: the generated section types get one added, and the types that already draw an icon (ferry, tollRoad) have theirs replaced.

    type SectionIconConfig = {
        image: string;
        placement?: "center" | "along";
        sizeFactor?: number;
    }
    Index

    Properties

    image placement? sizeFactor?

    Properties

    image

    image: string

    The id of an image in the loaded style's sprite, e.g. poi-toll_plaza. An id the sprite does not carry draws nothing.

    Optionalplacement

    placement?: "center" | "along"

    Where the icon sits on the section.

    Remarks

    • center: one icon at the middle of each section.
    • along: icons repeated along the section.

    Default Value

    "center" on the generated types; the bespoke types that draw an icon keep their own placement.

    OptionalsizeFactor

    sizeFactor?: number

    Icon scale, where 1 is the sprite image's own size. Clamped to SECTION_ICON_SIZE_FACTOR_RANGE, 0.25 to 2.

    Default Value

    1 on the generated types; the bespoke types that draw an icon keep their own zoom-ramped size.
