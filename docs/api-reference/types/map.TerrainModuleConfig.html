    Type Alias TerrainModuleConfig

    TerrainModuleConfig: MapModuleCommonConfig & {
        elevation?: TerrainElevationConfig;
        hillshade?: TerrainHillshadeConfig;
    }

    Configuration of the TerrainModule: the two ways it draws the relief of the style's elevation data.

    Type Declaration

    • Optionalelevation?: TerrainElevationConfig

      The 3D surface.

    • Optionalhillshade?: TerrainHillshadeConfig

      The hillshade shading.

    Remarks

    Unset, the hillshade is hidden like the other style parts the SDK adds (traffic flow and incidents), and the surface is left as the map draws it: flat on TomTom styles. So resetConfig() returns a TomTom style to flat and unshaded.

    Example

    const config: TerrainModuleConfig = {
        hillshade: { visible: true, method: 'multidirectional', shadowColor: '#3b2f2f' },
        elevation: { visible: true, exaggeration: 1.5 },
    };
