    Type Alias TrafficIncidentDetailsLayersConfig

    MapLibre overrides for the layers TrafficIncidentDetailsModule draws, bottom to top, for what its configuration doesn't cover.

    Remarks

    Each entry is a partial layer spec merged onto the module's own: top-level fields replace, layout and paint merge per property, and what is set here takes precedence over the module's own settings, the incident colours and the highlight included. Where the layers sit is beforeLayerConfig's, so a beforeID here is ignored.

    Example

    layers: {
        // Markers from zoom 11, and no delay text next to the jams
        incidentMarker: { minzoom: 11 },
        jamMarker: { layout: { 'text-field': '' } },
    }
    type TrafficIncidentDetailsLayersConfig = {
        closedRoadMarker?: Partial<
            ToBeAddedLayerSpecTemplate<SymbolLayerSpecification>,
        >;
        highlightHalo?: Partial<ToBeAddedLayerSpecTemplate<LineLayerSpecification>>;
        incidentMarker?: Partial<
            ToBeAddedLayerSpecTemplate<SymbolLayerSpecification>,
        >;
        innerChevron?: Partial<ToBeAddedLayerSpecTemplate<LineLayerSpecification>>;
        innerPattern?: Partial<ToBeAddedLayerSpecTemplate<LineLayerSpecification>>;
        innerSolid?: Partial<ToBeAddedLayerSpecTemplate<LineLayerSpecification>>;
        jamMarker?: Partial<ToBeAddedLayerSpecTemplate<SymbolLayerSpecification>>;
        outline?: Partial<ToBeAddedLayerSpecTemplate<LineLayerSpecification>>;
    }
