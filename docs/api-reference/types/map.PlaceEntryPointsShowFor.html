    Type Alias PlaceEntryPointsShowFor

    PlaceEntryPointsShowFor: "all" | "selected" | "clicked"

    Which shown places get their entry points drawn.

    Remarks

    • all - Every place that has entry points.
    • selected - Hovered or clicked places, which the selected layer highlights. A recently-hovered place counts too, so the pointer can cross the map to an entrance.
    • clicked - Clicked places, which stay clicked until the next click lands elsewhere.

    selected and clicked follow the module's event states, which exist once you register an event handler on the module or call PlacesModule.setEventState. Hovering or clicking an entry point keeps its place's entry points drawn if a handler on events or events.entryPoints covers them, not one on events.places alone.
