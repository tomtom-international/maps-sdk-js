    Properties for an EV charging station place.

    Extends common place properties with EV-specific charging park information. Use this type for places that are EV charging locations.

    Type Declaration

    • chargingPark: ChargingParkWithAvailability

      Charging infrastructure and availability information.

      Contains details about available connectors, counts, and optionally real-time availability status if fetched from the availability service.

    Example

    const evPlace: EVChargingStationPlaceProps = {
      // Common place properties
      id: 'place-123',
      type: 'POI',
      address: {...},
      position: [4.9, 52.3],
      // EV-specific properties
      chargingPark: {
        connectors: [...],
        availability: {...}
      }
    };
