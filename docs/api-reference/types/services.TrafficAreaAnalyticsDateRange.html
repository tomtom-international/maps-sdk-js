    Type Alias TrafficAreaAnalyticsDateRange

    The continuous date-range variant, which analyses traffic between startDate and endDate.

    • endDate is optional. If omitted, it defaults to three days ago, the latest date the service always has data for.
    • endDate falls one to 31 UTC calendar days after startDate.
    • Mutually exclusive with TrafficAreaAnalyticsDays.
    type TrafficAreaAnalyticsDateRange = {
        days?: never;
        endDate?: AreaAnalyticsDateInput;
        startDate: AreaAnalyticsDateInput;
    }

    The end date of the analysis period (inclusive), as a Date object or an ISO 'YYYY-MM-DD' string. By default, it is three days ago.

    Remarks

    It must be within 31 days from startDate, and no later than two days before today.
