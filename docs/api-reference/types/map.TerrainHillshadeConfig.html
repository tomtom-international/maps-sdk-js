    Type Alias TerrainHillshadeConfig

    The hillshade of the TerrainModule: light and shadow on the map surface that reveal hills, valleys and mountains, at any camera pitch.

    Remarks

    Everything but visible restyles the style's own hillshade layer, and reads the style's own value while unset. Those settings only show once visible does.

    type TerrainHillshadeConfig = {
        accentColor?: string;
        exaggeration?: number;
        highlightColor?: string;
        lightDirection?: number;
        maxZoom?: number;
        method?: HillshadeMethod;
        shadowColor?: string;
        visible?: boolean;
    }

    Properties

    OptionalaccentColor

    accentColor?: string

    Colour accentuating the steepest terrain.

    Optionalexaggeration

    exaggeration?: number

    Strength of the shading (0 = flat), not the height of the 3D surface (elevation.exaggeration). The standard styles ramp it to zero by zoom 13; setting it replaces the ramp with a constant.

    OptionalhighlightColor

    highlightColor?: string

    Colour of the lit slopes.

    OptionallightDirection

    lightDirection?: number

    Direction the light comes from, in degrees clockwise from north (335 is the cartographic default).

    OptionalmaxZoom

    maxZoom?: number

    Zoom level up to which the shading is drawn: the standard styles stop at 13, and 22 keeps it at every zoom.

    Optionalmethod

    method?: HillshadeMethod

    How the relief is shaded.

    Default

    The style's own; standard on TomTom styles.

    OptionalshadowColor

    shadowColor?: string

    Colour of the shaded slopes.

    Optionalvisible

    visible?: boolean

    Shows the hillshade.

    Default

    false
