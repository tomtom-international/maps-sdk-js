    The id of a places knob: its path into PlacesModuleConfig, e.g. markerType or cluster.badge.color. See placesKnobCatalogue for what each one does.

    Remarks

    Only settings that take a plain value: label.title, cluster.source.clusterProperties, evAvailability.formatText, connections.label.title and anything holding an image, a callback or MapLibre layers are not knobs.
