    Type Alias DistanceDisplayUnits

    Configuration for displaying distance-based units.

    Allows customization of distance unit labels and the unit system (metric or imperial) used throughout the SDK.

    type DistanceDisplayUnits = {
        feet?: string;
        kilometers?: string;
        meters?: string;
        miles?: string;
        type?: DistanceUnitsType;
        yards?: string;
    }
