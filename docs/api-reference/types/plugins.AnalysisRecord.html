    Type Alias AnalysisRecord

    One analysis tracked by the session-level Analyses registry, the single home for every analyseData analysis, one-shot or monitored, across every entry kind. It is pure sink state, metadata plus the bounded result history. The recipe (code / inputs) and recurrence are NOT here. They live on the analysis's Job (see _jobs). affectedEntryIds is the per-entry lookup key (Analyses.getAnalysesForEntry). history is the result timeline (oldest first), whose latest is the current result, threaded back into the sandbox code as previous.

    type AnalysisRecord = {

        analysisId: string;
