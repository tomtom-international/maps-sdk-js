    Properties

    Optionalanomalies

    anomalies?: Partial<Record<AreaAnalyticsMetricKey, AreaAnalyticsAnomaly[]>>

    Detected anomalies, keyed by metric. They are empty for trafficAreaAnalytics, as the service detects anomalies only over 35 days or more, beyond a request's 31-day limit.

    baseData

    baseData: AreaAnalyticsMetrics

    Overall aggregated traffic metrics for the full analysis period.

    level

    level: number

    Hierarchical level of the region in the analysis.

    Optionalname

    name?: string

    Name of the analysis region, which the API echoes from a request that names one. The SDK names none, so it is absent.

    OptionaltiledData

    tiledData?: { tiles: AreaAnalyticsTileEntry[] }

    Per-tile traffic metrics for the region, if heatmap data was requested.

    timedData

    timedData: AreaAnalyticsTimedData

    Traffic metrics broken down by time granularity.

    Optionaltimezone

    timezone?: string

    IANA timezone the API echoes from a request that names one. The SDK names none, so it is absent.
