    DisplayGeometryProps: CommonPlaceProps & ExtraGeometryDisplayProps

    Geometry base and display properties.

    They combine complete place information with geometry-specific display properties for rendering polygon features on the map.

    Remarks

    The GeometriesModule uses them to render:

    • Search API geometry results
    • Reachable range polygons
    • Custom polygon overlays
    • Administrative boundaries

    They include both geographic/metadata and visual styling properties.

    Example

    const geometry: DisplayGeometryProps = {
      type: 'Polygon',
      id: 'geom-123',
      title: 'Amsterdam',
      color: '#0080FF',
      address: {
        municipalitySubdivision: 'Amsterdam',
        countryCode: 'NL'
      }
    };
