    Type Alias EntryModeSliceName

    EntryModeSliceName: {
        [K in keyof ToolState]: ToolState[K] extends EntryModeSlice ? K : never
    }[keyof ToolState]

    The compile-time union of ToolState keys whose slice supports EntryMode. Names match the ToolState keys exactly, such as routing (not routes) and customGeometries (not geometries), so the slice name in the tool API never drifts from the property on state.

    When a new slice implements setEntryMode, the union picks up its key, and the runtime list ENTRY_MODE_SLICE_NAMES fails to type-check until the key is added there too.
