    Type Alias PlaceFilters

    What kind of places may come back. Everything here excludes results. A place that does not match is dropped, not ranked lower.

    Remarks

    Values within one member are OR'd. poiBrands: ['Shell', 'BP'] keeps a place of either brand. Members are AND'd with each other.

    Fuzzy search intersects it with GeographicFilters as SearchFilters, so one filters object carries the country and the attribute restrictions together.

    Example

    filters: { poiCategories: ['RESTAURANT', 'CAFE'] }
    filters: { poiBrands: ['Shell', 'BP'], fuelTypes: ['Diesel'] }
    filters: { connectors: ['IEC62196Type2CCS'], minPowerKW: 50, maxPowerKW: 150 }
    type PlaceFilters = {
        connectors?: ConnectorType[];
        fuelTypes?: Fuel[];
        geographyTypes?: GeographyType[];
        indexes?: SearchIndexType[];
        maxPowerKW?: number;
        minPowerKW?: number;
        poiBrands?: string[];
        poiCategories?: POICategory[];
    }
