    Geocodes query restricted to administrative area geographies (not streets/POIs), biased toward bias (the map centre). Because geographyTypes filters to areas, every result carries a boundingBox. Callers choose among the candidates, for example the one nearest the current view. A centre bias is used rather than a hard viewport-bbox filter, so out-of-view areas still resolve.
