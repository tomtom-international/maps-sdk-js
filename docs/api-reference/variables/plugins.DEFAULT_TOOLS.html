    Default tool set for the agent toolkit. Each entry is a ToolDefinition — either a static ToolEntry or a ToolEntryBuilder that tailors the tool to ToolBuildOptions (e.g. feature flags) at agent-creation time.

    Included automatically by createMapAgent unless includeDefaultTools is false. Use resolveTools() for manual composition outside createMapAgent.
