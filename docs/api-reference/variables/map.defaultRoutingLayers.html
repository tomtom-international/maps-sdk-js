    Variable defaultRoutingLayersConst

    defaultRoutingLayers: Required<RouteLayersConfig> = ...

    Default routing layers configuration. Calls routingLayers with no parameters.

    Remarks

    This configuration defines the complete visual styling for all route-related map layers, including main route lines, waypoints, special road sections (ferries, tunnels, toll roads, etc.), turn-by-turn guidance instructions, and route summary information.

    Usage:

    • Automatically applied when initializing RoutingModule without custom layer configuration
    • Can be used as a reference or starting point for creating custom layer configurations
    • Individual properties can be selectively overridden while keeping defaults for others

    See

    • RouteLayersConfig for the configuration type definition
    • RoutingModule.get for initialization options
    • RoutingModule.applyConfig for runtime configuration updates
