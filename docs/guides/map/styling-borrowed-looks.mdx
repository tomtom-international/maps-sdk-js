Some parts the data-owned modules draw are meant to look like part of the style, so they take their look from it. They follow the knobs that restyle what they borrow: the [Styling Foundations module](./styling.mdx)'s sizes, and the look knobs of the [POIs](./pois.mdx#appearance) and [traffic incidents](./traffic-incidents.mdx#appearance) modules. They update live, whether you set the knob before or after creating the module, and across a `setStyle`.

## What each module borrows

| Module | What it borrows | The knobs it follows | Your own look instead |
| --- | --- | --- | --- |
| [`PlacesModule`](./places-styling.mdx#marker-type), `base-map` marker type | the POI labels and icons | `POIsModule` `label.color`, `label.haloColor`, `sizeFactor`; Styling `labels.sizeFactor`, `symbols.sizeFactor` | `label`, or a `layers` override |
| `PlacesModule`, `circle-icon` marker type | the icon size | `POIsModule` `sizeFactor`; Styling `symbols.sizeFactor` | a `layers` override |
| `PlacesModule`, `pin-clustered` marker type | the micro markers | `POIsModule` `sizeFactor`; Styling `symbols.sizeFactor` | a `layers` override |
| [`RoutingModule`](./routes-sections.mdx) | the delay colour of a `traffic` section | `TrafficIncidentsModule` `colors.minor`, `colors.moderate`, `colors.major` | a `line-color` under `layers.sections.traffic.routeIncidentBackgroundLine` |
| [`TrafficIncidentDetailsModule`](./traffic-incident-details.mdx) | the line colour of each incident magnitude | `TrafficIncidentsModule` `colors.minor`, `colors.moderate`, `colors.major`, `colors.closed` | None. The module always draws the style's incident colours. |

```javascript
import { PlacesModule, POIsModule, poisKnobCatalogue, setKnob } from '@tomtom-org/maps-sdk/map';

const places = await PlacesModule.create(map, { markerType: 'base-map' });
const pois = await POIsModule.get(map);
setKnob(pois, poisKnobCatalogue, 'label.color', '#be185d'); // the places' labels turn with the map's POIs
```

## Who wins

- Your own look wins over the knob.
- If you set none of its knobs, a route keeps the SDK's own delay colours, which match the incidents of the light styles.
- The `pin` marker type borrows nothing, and no knob reaches it.
- The knob still writes only the style's layers. The module reads the new look and redraws its own ([Who owns what](./modules.mdx#who-owns-what)).
