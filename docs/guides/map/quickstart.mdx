Install the SDK, set your API key and show an interactive TomTom map, as in the demo below.

## Prerequisites and setup

1. **Node.js 24+** and npm or pnpm
2. **TomTom API key** from [my.tomtom.com](https://my.tomtom.com/)
3. **A browser with WebGL**, which MapLibre renders with

<Blockquote>
    **Before you ship, decide where this key will live.** A key used from the browser can be read by anyone who opens the page. A key used from Node.js cannot. See [Where your API key runs](../security/where-your-api-key-runs.mdx) for which case you are in and what to do about it, and TomTom's [API key management best practices](https://docs.tomtom.com/platform/documentation/api-best-practices/api-key-management-best-practices) for key restrictions, rotation and monitoring.
</Blockquote>

## Installing dependencies

```bash
# npm or Yarn - automatic peer dependency installation
npm install @tomtom-org/maps-sdk

# pnpm - enable auto-install-peers for easiest setup
echo "auto-install-peers=true" >> .npmrc
pnpm install @tomtom-org/maps-sdk
```

`maplibre-gl` and the SDK's other peer dependencies install with it. The [Project setup guide](../../introduction/project-setup.mdx) lists [which peer dependencies each bundle needs](../../introduction/project-setup.mdx#peer-dependency-requirements-by-bundle) and how to install them by hand.

## Basic HTML setup

The map container needs a height, or the map renders with none:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>TomTom Map Application</title>
    <style>
        #map { width: 100%; height: 400px; }
    </style>
</head>
<body>
    <div id="map"></div>
    <script type="module" src="./index.ts"></script>
</body>
</html>
```

## Creating your first map

```javascript
import { TomTomConfig } from '@tomtom-org/maps-sdk/core';
import { TomTomMap } from '@tomtom-org/maps-sdk/map';

TomTomConfig.instance.put({ apiKey: 'YOUR_API_KEY' });

const map = new TomTomMap({
    mapLibre: {
        container: 'map'
    }
});
```

The map opens in the default `standardLight` style. The SDK applies the MapLibre CSS itself, so there is no stylesheet to import ([MapLibre CSS](./about-maplibre.mdx#maplibre-css)).
