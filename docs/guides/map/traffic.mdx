The TomTom Maps SDK provides real-time traffic visualization in different ways, each optimized for specific use cases.

<GuideDemo demo="traffic-config-playground" />

## Traffic incidents

**[TrafficIncidentsModule](./traffic-incidents.mdx)** displays real-time traffic events across the entire map area, such as accidents, road closures, construction, and weather disruptions. Each incident shows its type, severity, affected road segments, and expected delay impact.

**Use when:** You need to display and filter traffic events (accidents, closures, construction) across the map.

## Traffic flow

**[TrafficFlowModule](./traffic-flow.mdx)** displays real-time traffic speed conditions across the entire road network using color-coded road segments. Green indicates free-flowing traffic, yellow/orange represents moderate speeds, red shows congestion, and dark gray indicates road closures.

**Use when:** You need a comprehensive view of current traffic conditions across all visible roads on the map.

## Traffic flow as data

Live flow on Orbis is vector tiles only, so `TrafficFlowModule.getShown()` over the current viewport is the only way to read it as data. [What the flow data can and cannot tell you](./traffic-flow.mdx#what-the-flow-data-can-and-cannot-tell-you) lists what each segment carries; for historical speed and congestion over an area, use **[Traffic Area Analytics](../services/traffic/traffic-area-analytics.mdx)**.

## Traffic along routes

**[RoutingModule](./routes.mdx)** displays traffic incidents specifically along calculated routes, showing only incidents that directly affect the planned path. This focused view helps users understand delays and hazards affecting their specific journey.

**Use when:** You need to show traffic incidents relevant to a specific calculated route.

## Traffic area analytics

**[TrafficAreaAnalyticsModule](./traffic-area-analytics-module.mdx)** visualizes historical traffic data for a geographic region using hexagonal/square grids or a heatmap. Data is fetched from the TomTom Move Portal API and supports multiple metrics (congestion, speed, travel time) coloured with a named palette or your own colour stops.

**Use when:** You need to analyze historical traffic patterns for a specific city or region.
