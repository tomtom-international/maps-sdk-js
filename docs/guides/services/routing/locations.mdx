`locations` is the ordered list a route passes through. Each entry is one of two kinds:

- A waypoint is a single point the route stops at. Every waypoint ends a leg, with an arrival
  instruction. There is no "pass-through" waypoint.
- A path is a sequence of points the route must follow, for
  [route reconstruction](#path-arrays).

A request needs at least two waypoints, or one path on its own.

<Blockquote type="announcement" hasIcon>

  Maximum 150 waypoints per route.

</Blockquote>

## Single point waypoints

### Coordinate pairs

`[longitude, latitude]` pairs:

```javascript
import { calculateRoute } from '@tomtom-org/maps-sdk/services';

const routes = await calculateRoute({
    locations: [
        [4.897070, 52.377956],  // Amsterdam
        [4.288788, 52.078663],  // The Hague
        [4.462456, 51.926517]   // Rotterdam
    ]
});
```

### GeoJSON points and features

A GeoJSON `Point`, or any `Feature<Point>`, is a waypoint too, so you can pass geocoding and search
results unchanged:

```javascript
import { calculateRoute, geocodeOne } from '@tomtom-org/maps-sdk/services';

const waypoints = await Promise.all([
    geocodeOne('Amsterdam, Netherlands'),
    geocodeOne('The Hague, Netherlands'),
    geocodeOne('Rotterdam, Netherlands')
]);

const routes = await calculateRoute({ locations: waypoints });
```

- A place with entry points is routed to its geometry, unless you set
  `useEntryPoints: 'main-when-available'`, which routes to its main entrance instead
  ([Entry points](./parameters.mdx#entry-points)).
- A waypoint feature's `properties` carry its per-stop options (the wait there, the arriving leg's
  cost model, candidate entrances). [Per-stop options](./parameters.mdx#per-stop-options) lists them.

## Path arrays

A path forces the route along given coordinates. Its first and last points become stops as well, so
it shapes the route without removing a leg:

```javascript
import { calculateRoute } from '@tomtom-org/maps-sdk/services';

const routes = await calculateRoute({
    locations: [
        [4.9, 52.3],  // Origin waypoint
        [
            [4.85, 52.25],  // Path points
            [4.80, 52.20],
            [4.75, 52.15]
        ],
        [4.5, 51.9]   // Destination waypoint
    ]
});
```

A route feature from an earlier call is a path as well, and keeps its leg boundaries as stops:

```javascript
const utrechtToRotterdam = await calculateRoute({
    locations: [[5.1230, 52.0919], [4.4624, 51.9265]]
});

const routes = await calculateRoute({
    locations: [
        [4.8970, 52.3779], // Amsterdam
        utrechtToRotterdam.features[0],
        [2.3522, 48.8566]  // Paris
    ]
});
```

## Displaying waypoints on map

`RoutingModule.showWaypoints` takes the same waypoints, but not paths, and `clearWaypoints` removes the pins:

```javascript
await routingModule.showRoutes(routes);
await routingModule.showWaypoints(waypoints);
```

[Waypoints](../../map/routes.mdx#waypoints) in the routing module guide covers the pins, their labels
and their events. To insert a stop at the best position in an existing list, use a
[core route utility](../../core/utilities/routes.mdx).
