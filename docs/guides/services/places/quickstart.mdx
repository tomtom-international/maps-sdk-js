The places services find places by text, area or route, turn addresses into coordinates and back,
and return each result as a GeoJSON [place](../../core/places.mdx) that the
[Places module](../../map/places.mdx) shows without mapping fields first.

## Basic setup

```javascript
import { TomTomConfig } from '@tomtom-org/maps-sdk/core';

TomTomConfig.instance.put({ apiKey: 'YOUR_API_KEY' });
```

The [global configuration](../../core/global-config.mdx) also sets the language and the
geopolitical view every call inherits; a single call overrides them as in
[Request options and errors](../request-options-and-errors.mdx#per-call-overrides).

## Quick examples

### Search for places

```javascript
import { discoverPlaces } from '@tomtom-org/maps-sdk/services';

const results = await discoverPlaces({
    query: 'coffee shops',
    geoBias: { position: [4.9041, 52.3676] }, // Amsterdam
});

console.log(results.features[0].properties.poi?.name);
```

### Geocode an address

```javascript
import { geocodeOne } from '@tomtom-org/maps-sdk/services';

const place = await geocodeOne('Dam Square, Amsterdam');
const coordinates = place.geometry.coordinates; // [lng, lat]
```

### Reverse geocode coordinates

```javascript
import { reverseGeocode } from '@tomtom-org/maps-sdk/services';

const place = await reverseGeocode({ position: [4.9041, 52.3676] });
console.log(place.properties?.address?.freeformAddress);
```
