The EV Charging Stations Availability service adds real-time status to the electric vehicle charging stations
the search services return: the status of each charging point, and counts per connector type and power level.

In the demo below, each searched station shows its free and total charging points under its pin;
click one to list its connectors and charging points.

<GuideDemo demo="ev-charging-stations-search" />

## Basic usage

```javascript
import { discoverPlaces, getPlacesWithEVAvailability } from '@tomtom-org/maps-sdk/services';

// First, search for EV charging stations
const stations = await discoverPlaces({
    query: 'EV charging',
    geoBias: { position: [4.9041, 52.3676] }, // Amsterdam
    filters: { poiCategories: ['CHARGING_LOCATION'] },
    limit: 10
});

// Fetch real-time availability data
const stationsWithAvailability = await getPlacesWithEVAvailability(stations);
```

## Cancelling the availability calls

`getPlacesWithEVAvailability` sends one request per station, one after the other, so a large
result set takes a while. Pass a `signal` in the options when a newer search or a map move
supersedes it: aborting cancels the in-flight request, skips the remaining stations and rejects the
call with an `SDKAbortError`, as for
[any other service call](../request-options-and-errors.mdx#cancelling-a-request).

[`createLatestRequest`](../request-options-and-errors.mdx#keeping-only-the-latest-request)
keeps only the newest run: starting one stops the previous one working through its list.

```javascript
import { createLatestRequest, getPlacesWithEVAvailability } from '@tomtom-org/maps-sdk/services';

const latestAvailability = createLatestRequest();

const showAvailability = async (stations) => {
    const availability = await latestAvailability.run((signal) =>
        getPlacesWithEVAvailability(stations, { signal })
    );
    if (availability.current) await placesModule.show(availability.value);
};
```

## Individual station availability

Get availability for a specific charging station. It takes the same `signal`, and an abort rejects
the call the same way; every other request failure resolves to `undefined`.

```javascript
import { getPlaceWithEVAvailability } from '@tomtom-org/maps-sdk/services';

// Get a specific charging station (from search results)
const station = stations.features[0];

const stationWithAvailability = await getPlaceWithEVAvailability(station);
if (stationWithAvailability) {
    const { count, statusCounts } = stationWithAvailability.properties.chargingPark.availability.chargingPointAvailability;
    console.log(`${statusCounts.Available ?? 0} of ${count} charging points available`);
}
```

A place without a `dataSources.chargingAvailability.id` resolves to `undefined` without a request.

## Charging stations and points on search results

An EV search result already describes its hardware in `place.properties.chargingPark`, without
real-time status; [EV charging stations](../../core/places.mdx#ev-charging-stations) lists its
fields. Only one of a charging point's connectors can charge at a time.

```javascript
const { chargingPark } = stations.features[0].properties;

chargingPark?.connectors.forEach(({ connector, count }) => {
    console.log(`${count} × ${connector.type}, ${connector.ratedPowerKW} kW (${connector.chargingSpeed})`);
});

chargingPark?.chargingStations?.forEach((chargingStation) => {
    chargingStation.chargingPoints.forEach((point) => {
        const plugs = point.connectors?.map((connector) => connector.type).join(' or ');
        console.log(`${point.evseId ?? chargingStation.id}: ${plugs}`);
        if (point.capabilities.includes('PlugAndCharge')) console.log('  Plug & Charge');

        if (point.restrictions.includes('Customers')) console.log('  customers only');
    });
});
```

## Understanding availability data

`getPlaceWithEVAvailability` adds `chargingPark.availability`. A place with no `chargingPark` of its
own, such as a [route charging stop](../routing/long-distance-ev-routing.mdx), also gets
`chargingPark.connectors`, counted from the availability, but no static `chargingStations`:

- `chargingPointAvailability` – The `count` of charging points and their `statusCounts` by `Available`, `Reserved`, `Occupied`, `OutOfService` or `Unknown`; a status appears only when a point has it
- `connectorAvailabilities` – Connectors counted per type and power, each with its `connector`, `count` and `statusCounts` by the status of its charging point
- `chargingStations` – The same station → charging point → connector hierarchy, each charging point with its `status`
- `accessType` – `Public`, `Authorized`, `Restricted`, `Private` or `Unknown`
- `openingHours` – When the park is open; it also replaces `poi.openingHours`

`getPlacesWithEVAvailability` returns a station whose availability is unknown unchanged, so guard each
one with `hasChargingAvailability`:

```javascript
import { hasChargingAvailability } from '@tomtom-org/maps-sdk/services';

stationsWithAvailability.features.forEach((station) => {
    const { chargingPark } = station.properties;
    if (!hasChargingAvailability(chargingPark)) return;

    const { accessType, connectorAvailabilities, chargingStations } = chargingPark.availability;
    console.log(`Access: ${accessType}`);

    connectorAvailabilities.forEach(({ connector, count, statusCounts }) => {
        console.log(`${connector.type}, ${connector.ratedPowerKW} kW: ${statusCounts.Available ?? 0}/${count} available`);
    });

    chargingStations.forEach((chargingStation) => {
        chargingStation.chargingPoints.forEach((point) => {
            console.log(`${point.evseId ?? chargingStation.id}: ${point.status}`);
        });
    });
});
```

## Integration with map display

`PlacesModule` labels each station with its available and total charging points once you enable
`evAvailability`, green when the available share reaches `threshold` and red below it:

```javascript
import { PlacesModule } from '@tomtom-org/maps-sdk/map';

const placesModule = await PlacesModule.create(map, {
    evAvailability: {
        enabled: true,
        threshold: 0.3,
        formatText: (available, total) => `${available} of ${total} free`,
    },
});

await placesModule.show(stationsWithAvailability);
```

## Filtering by connector type

Keep the stations with a free connector of the types your vehicle takes:

```javascript
import { hasChargingAvailability } from '@tomtom-org/maps-sdk/services';

const hasFreeConnector = (station, connectorTypes) =>
    hasChargingAvailability(station.properties.chargingPark) &&
    station.properties.chargingPark.availability.connectorAvailabilities.some(
        ({ connector, statusCounts }) => connectorTypes.includes(connector.type) && (statusCounts.Available ?? 0) > 0,
    );

const compatibleStations = {
    ...stationsWithAvailability,
    features: stationsWithAvailability.features.filter((station) =>
        hasFreeConnector(station, ['IEC62196Type2CCS', 'Chademo']),
    ),
};
```
