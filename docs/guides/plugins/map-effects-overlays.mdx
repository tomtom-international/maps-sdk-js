Five of the [map effects](./map-effects.mdx) are overlays on the map. Grade and tint mute the base map so your data stands out. Fog and edge blur add depth or focus at the view's rim, and vignette darkens or lightens the edges. Each is off by default. The playground below shows them on one panel with the other effects.

## Muting the base map: grade and tint

`grade` sets the brightness, contrast and saturation of the whole frame, and `tint` lays a colour over it. Together they quiet the base map under your own data layers. They are the visual half of the [`data-viz` styling preset](../map/styling.mdx#presets), which quiets the map's content.

```javascript
effects.updateConfig({ grade: { saturation: 0.4, brightness: 0.85 }, tint: { opacity: 0.15 } });
```

## Fog or edge blur?

Both blur the view's rim and take a `reach`. They differ in what happens to the rim's colour:

- Fog *also* washes the rim towards the colour of the air. It reads as distance.
- Edge blur leaves the colour alone, so it reads as a lens. Use it when the rim's colour still carries data.

Use fog for depth and edge blur for focus. Together they compound, which is rarely what you want.

```javascript
effects.updateConfig({ fog: { intensity: 0.6, reach: 0.4 } });
```

By default, the air follows the map's light/dark theme: pale over a light style and dark over a dark one. To give the air a colour of your own, such as a milky haze over a dark style, set `fog.color`. The colour's lightness also brightens or darkens the rim under it, and a translucent colour does both less. To go back to the theme's air, reset the knob.

```javascript
effects.updateConfig({ fog: { intensity: 0.6, reach: 0.4, color: '#e6ecf2' } });
```

## Vignette

A negative `vignette.intensity` darkens the edges and a positive one lightens them. `vignette.reach` sets how far in it reaches.

```javascript
import { setKnob } from '@tomtom-org/maps-sdk/map';
import { effectKnobCatalogue } from '@tomtom-org/maps-sdk-plugin-map-effects';

setKnob(effects, effectKnobCatalogue, 'vignette.intensity', -0.5);
```

## The knobs

| Knob | Range | Default |
| --- | --- | --- |
| `grade.brightness`, `grade.contrast` | 0.5–1.5 | 1 |
| `grade.saturation` | 0–1.5 | 1 |
| `tint.color`, `tint.opacity` | colour, 0–1 | `#1f2937`, 0 (off) |
| `fog.intensity`, `fog.reach` | 0–1 | 0 (off), 0.4 |
| `fog.color` | colour | The air of the map's light/dark theme |
| `edgeBlur.intensity` (CSS px), `edgeBlur.reach` | 0–30, 0–1 | 0 (off), 0.5 |
| `vignette.intensity` (negative darkens, positive lightens), `vignette.reach` | −1–1, 0–1 | 0 (off), 0.45 |

The ranges of `grade.brightness`, `grade.contrast`, `grade.saturation` and `edgeBlur.intensity` end where a slider would. `setKnob` refuses a value below the minimum, and a value above the maximum still applies. Every other range holds at both ends.

## How they render

Grade, fog and edge blur are `backdrop-filter` layers, vignette is a gradient and tint is a flat layer. They stack over the [GPU chain's result](./map-effects.mdx#how-it-renders) and the bloom. Because they are CSS, they need no redrawing as the map moves, and they don't need a readable map canvas.
