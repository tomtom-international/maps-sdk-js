The Agent Toolkit turns a TomTom map into something a user can talk to. Bring an LLM and a chat box, and your users
plan routes, search for places, inspect traffic and reshape the map with sentences instead of clicks.

<GuideDemo demo="map-chat-agent-react" />

## What you can build with it

- **Conversational route planning.** *"Drive me from Berlin to Munich avoiding tolls, and stop for coffee halfway."* —
  the agent chains geocoding, routing, place search and route edits, and renders the result.
- **Operational dashboards.** *"Show me where congestion is worst right now, and chart how many of our vehicles are in
  it."* — the traffic tools next to [custom tools](./customizing-tools.mdx) that read your own fleet data.
- **Self-explaining field tools.** *"Outline every neighbourhood unreachable from the hospital in 20 minutes."* —
  isochrones plus [generated code](./code-generation.mdx) produce and render a derived polygon.
- **Exploring your own data.** Load a GeoJSON file and ask *"keep only the points inside the congested tiles"* — the
  agent registers it as a [BYOD layer](./byod.mdx) and filters it.

## What's in the box

`@tomtom-org/maps-sdk-plugin-agent-toolkit` is a **headless** plugin built on [Vercel AI SDK](https://ai-sdk.dev/) v6.
`createMapAgent` returns a `ToolLoopAgent` wired to a `TomTomMap` and the TomTom services.

**You bring:**
- A model from any [Vercel AI SDK provider](https://ai-sdk.dev/providers/ai-sdk-providers) (OpenAI, Anthropic, Azure,
  Google, …).
- A chat UI, or programmatic `agent.generate()` / `agent.stream()` calls.

**The plugin provides:**
- A [tool registry](./tools.mdx) covering search, routing, traffic, isochrones, your own GeoJSON, base-map control,
  MapLibre access and generated analysis.
- An [intent classifier](./how-it-works.mdx) that offers only the tools each turn needs.
- [Shared state](./state.mdx) — places, routes, ranges, incidents, derived polygons, your own layers — that survives
  across turns, so *"add a stop after the second one"* just works.
- [Data tools](./scope-aware-data-tools.mdx) that run model-written JavaScript over that state in a sandbox.
- Ways to [add, remove or replace tools](./customizing-tools.mdx) and to
  [shape the system prompt](./customizing-system-prompt.mdx).

## Quickstart

<Blockquote>
    All plugins use `@tomtom-org/maps-sdk` as a peer dependency — ensure the SDK is installed first.
    See the [Project Setup guide](../../../introduction/project-setup.mdx) if needed.
</Blockquote>

### Install

```bash
npm install @tomtom-org/maps-sdk-plugin-agent-toolkit ai zod
npm install @ai-sdk/react @ai-sdk/openai   # or @ai-sdk/anthropic, @ai-sdk/azure, …
```

The plugin's other peer dependencies — `@tomtom-org/maps-sdk-plugin-map-theme`, `maplibre-gl`, `@turf/turf`, `chart.js`,
`h3-js` — are installed automatically by npm 7+ and pnpm 8+; add them yourself with other package managers.

### Wire it up

```typescript
import { TomTomConfig } from '@tomtom-org/maps-sdk/core';
import { TomTomMap } from '@tomtom-org/maps-sdk/map';
import { createMapAgent } from '@tomtom-org/maps-sdk-plugin-agent-toolkit';
import { openai } from '@ai-sdk/openai';
import { useChat } from '@ai-sdk/react';
import { DirectChatTransport } from 'ai';

TomTomConfig.instance.put({ apiKey: 'YOUR_API_KEY' });

const map = new TomTomMap({ mapLibre: { container: 'map' } });

const agent = createMapAgent(map, {
    model: openai('gpt-4o'),
    dataEntries: {
        routes: { entryMode: 'single' }, // one route on the map at a time
        byod: { enabled: false },        // no bring-your-own-data tools in this deployment
    },
});

const { messages, sendMessage } = useChat({
    transport: new DirectChatTransport({ agent }),
});
```

Without a chat UI, call the agent directly:

```typescript
const { text } = await agent.generate({
    messages: [{ role: 'user', content: 'Find coffee shops near Dam Square' }],
});
```

### Try it out

- *"Route from Berlin to Munich avoiding tolls."*
- *"Show coffee shops near the map centre."*
- *"What traffic incidents are on this route?"*
- *"Switch to dark mode."*
- *"How far is the second stop?"*
- *"Chart the incidents along the route by category."*

### Clean up

```typescript
agent.destroy(); // resets every built-in and custom state slice that implements reset()
```

## Options

`createMapAgent(map, options)` takes one required option, `model`; each other option is explained on the page that owns
it.

| Option | What it controls | Read |
|---|---|---|
| `tools`, `includeDefaultTools` | Add, remove, replace or hand-pick tools | [Customizing tools](./customizing-tools.mdx) |
| `systemPrompt`, `systemPromptPrefix`, `systemPromptSuffix` | The system prompt | [Customizing the system prompt](./customizing-system-prompt.mdx) |
| `classifier`, `onClassify` | Per-turn tool selection | [How it works](./how-it-works.mdx#1-intent-classification) |
| `prepareStep`, `maxSteps`, `stepProviderOptions`, `providerOptions`, `outputSchemas` | The tool loop | [How it works](./how-it-works.mdx#2-tool-loop) |
| `onToolExecute` | Per-tool timing and errors | [How it works](./how-it-works.mdx#2-tool-loop) |
| `state`, `dataEntries` | Custom state slices; which data kinds exist and their entry mode | [State](./state.mdx) |
| `byod` | Which URLs the agent may fetch | [Bring your own data](./byod.mdx#restricting-which-urls-may-be-fetched) |
| `codeExecution` | Sandbox timeout and worker libraries | [Code generation](./code-generation.mdx#data-tool-execution-isolation-experimental) |
